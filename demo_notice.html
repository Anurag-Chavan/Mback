The real Mback dashboard is a private, localhost-only tool — it runs at http://127.0.0.1:5000 on the owner’s own machine, reads their real backup_state.db, and can trigger a real backup run. It is never deployed publicly.

Any public visual demonstration of this project — screenshots for a CV, a LinkedIn post, or a static walkthrough — is produced with DEMO_MODE = True, which switches every page to a bundled, entirely fictional dataset (static/demo_data.json). In that mode:

  • No real mailbox credentials, customer data, message content, attachments, logs, or actual backup files are shown, ever.
  • All folder names, subjects, and filenames are clearly fictional (for example, demo-client@example.test, “Sample Invoice — Demo Only”, “Project Update — Sample”).
  • “Run Backup Now” and opening a backup file are both disabled — demo mode cannot trigger any real action.
  • Every page displays the “Demo data only” banner shown above whenever demo mode is active.
